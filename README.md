# منظّم قوائم التشغيل الصوتية

**الإصدار الحالي: `v0.9-271026`** (الصيغة: رقم الإصدار – تاريخ الإصدار `ddmmyy` = 27‑10‑2026)

برنامج بواجهة رسومية احترافية (PySide6، وضع ليلي افتراضي) لبناء برامج بث يومية
من مكتبة دروس/خطب/محاضرات صوتية، مع بادئات وفواصل تلقائية وبدائل خاصة
(فجر/مساء/جمعة)، ثم تخريج كل يوم إلى مجلد مستقل. **تبويب "حول" داخل البرنامج
نفسه يحوي شرحاً تفصيلياً كاملاً لكل الميزات وطريقة الاستخدام**، وهذا الملف
يقتصر على التشغيل والبنية التقنية.

## الجديد في الإصدار 0.04

- **دقة زمنية**: كل فقرة (30/60 دقيقة...) وكل 8 و24 ساعة تنتهي في موعدها ± "دقة إغلاق الفقرة" (ثانية افتراضياً) بمؤشر زمني لا تتراكم أخطاؤه.
- اختيار الفواصل عشوائي لكل ملف ضمن المدة والنسبة المقبولتين، مع تقليل تكرار الفاصل خلال اليوم.
- فحص البادئات (مطابقة رقم + نوع) واحتساب مدتها في عرض المواد؛ تصدير/استيراد نتائجها.
- حماية البيانات: تأكيد قبل أي حذف تلقائي، تراجع شامل، ترتيب عشوائي ذرّي.
- أمان التخريج: فحص الملفات والمساحة، سؤال عند وجود مجلد يوم، نسخ عبر ملف مؤقت، إيقاف، دمج الجدول الشامل.
- حفظ تلقائي عند الإغلاق + "استعادة الجلسة الأخيرة"؛ زر "تطبيق على النتائج الحالية" للاستثناءات.
- إبطال المعاينة القديمة، حماية خيوط الفحص، تحقق من نسب الفواصل، لقطات ثابتة للبناء.

## التبويبات

1. **سلاسل المواد** — فحص مجلد السلاسل ومجلد البادئات وفق أسماء المجلدات/
   الملفات الفعلية (بلا أي تهيئة يدوية)، بجدول قابل للفرز والتحديد المتعدد
   (Ctrl+A، Shift+نطاق) وبحث فوري، وعمود "مدة الحجز" وعمود لفتح مجلد أي
   سلسلة بنقرة مزدوجة. **تصدير/استيراد نتائج الفحص** إلى/من ملف JSON واحد
   (مفيد لمكتبة ضخمة، لتفادي إعادة قراءة آلاف الملفات في كل اختبار للبرنامج).
2. **ترتيب 8 ساعات** — لوحة Block Puzzle لترتيب السلاسل: طول كل شكل بعدد
   موادها، وعرض **كل مادة على حدة** (وليس عرضاً موحّداً للسلسلة) بحسب مدتها
   هي (نصف ساعة=عمود، ساعة=عمودان...)، فتظهر السلاسل متفاوتة المدد كأشكال
   متدرّجة (سلّم). خيار "ملء الفراغات بين السلاسل بفواصل" لبناء يوم متواصل
   24 ساعة حتى مع وجود فجوات باللوحة. سحب/إفلات، حذف (Delete)، تراجع
   (Ctrl+Z)، وترتيب عشوائي متوازن بلا فراغات.
3. **ترتيب 24 ساعة** — عرض للقراءة فقط يُظهر نمط الثمان ساعات مكرراً ليغطي
   يوماً كاملاً (48 عموداً)، مع إعداد ثلاثة بدائل: الفجر والمساء (يوميان)
   والجمعة (عدة ملفات تُعامَل كمادة واحدة مجمّعة، كل جمعة فقط).
4. **الفواصل** — فحص مجلد الفواصل الرئيسي، وجدول نسبتي كل نوع فاصل (الوجود
   خلال اليوم / تحديد المدة)، مع **ترتيب أولوية الظهور** بين الأنواع (أزرار
   تحريك لأعلى/لأسفل — النوع الأول بالجدول يُملأ أولاً في كل فترة، ثم الثاني،
   وهكذا، دون تعارض مع النسبتين)، و**بادئة اختيارية لكل نوع** (ملف واحد
   يُدرَج قبل كل ملف يُختار من ذلك النوع تحديداً)، مع نفس ميزة **تصدير/
   استيراد نتائج الفحص**.
5. **استثناءات** — جدول أسماء ملفات (وليس مسارات) تُستبعد تلقائياً أينما
   وُجدت في أي فحص لاحق (سلاسل، بادئات، فواصل)، بإضافة ملف/عدة ملفات أو كل
   ملفات مجلد كامل دفعة واحدة.
6. **المعاينة** — مجلد الإخراج، مجال تاريخ التخريج، بناء معاينة يومية كاملة
   (بلا نسخ) وتأكيد التخريج الفعلي (مجلد مستقل لكل يوم باسم تاريخه). لكل صف
   بجدول المعاينة: تشغيل الملف الأصلي بمشغل خارجي، أو الذهاب إلى موقعه في
   مستكشف الملفات (نقر مزدوج، زران مخصصان، أو قائمة بالزر الأيمن).
7. **الإعدادات** — مدة الفقرة، طول اليوم المعروض، هامش تسامح المطابقة، وزر
   تصدير/استيراد **كل** بيانات المشروع دفعة واحدة (كل التبويبات معاً).
8. **حول** — شرح تفصيلي شامل لكل قسم وميزة وطريقة استخدام، بالعربية.

قائمة منسدلة أعلى يسار النافذة (بعد تبويب "حول") تبدّل بين 4 أوضاع مظهر
(وضعان ليليان ووضعان نهاريان، لكل واحد لون مميّز مختلف للأزرار وعناصر
التمييز)، وتُحفظ تلقائياً لآخر اختيار.

كل الجداول تعرض 10 أسطر افتراضياً مع تمرير لرؤية الباقي، وكل تبويب قابل
للتمرير أيضاً. كل المسارات والخيارات تُحفظ تلقائياً بين مرات التشغيل، وجميع
حقول المسارات تقبل السحب والإفلات المباشر من خارج البرنامج.

## بنية تسمية الملفات المطلوبة

- **مجلد سلسلة**: نمط الاسم `MK-023Sp-SإيمانياتS` (الرقم 023، رمز النوع Sp
  = خطبة، الاسم "إيمانيات"). رموز الأنواع: Le=درس، Sp=خطبة، Pr=برنامج،
  Qu=سؤال وجواب، Co=دورة، Se=محاضرة، Br=فاصل. إن لم يطابق اسم المجلد هذا
  النمط، يُستخرج رقم السلسلة تلقائياً من أسماء ملفات موادها بدلاً منه.
- **ملف مادة**: نمط الاسم يبدأ بـ `023Sp004-...` (رقم السلسلة 023، المادة
  رقم 4). يُختار أكبر ملف حجماً لكل رقم مادة.
- **ملف بادئة** (بمجلد البادئات المشترك): نمط الاسم يبدأ بنفس رقم السلسلة،
  مثال `023Sp000-...` = بادئة السلسلة 023، وتُستخدم لكل مواد تلك السلسلة.

## عرض المواد في لوحة الترتيب (مدة الحجز)

عرض كل **مادة** (بالأعمدة/الفترات) يُحسب من **مدتها هي تحديداً** (وليس من
أطول مادة في السلسلة كلها): أقل من نصف ساعة = عمود واحد، بين نصف ساعة
وساعة = عمودان، بين ساعة وساعة ونصف = ثلاثة أعمدة، وهكذا (مضاعفات نصف
الساعة). كل مواد السلسلة تشترك بنفس عمود البداية، فتظهر السلاسل متفاوتة
مدد المواد كأشكال متدرّجة (سلّم)، والفراغات الجانبية الناتجة تبقى قابلة
للاستخدام من سلاسل أخرى أصغر. عمود "مدة الحجز" بتبويب سلاسل المواد يعرض
المدى (الأدنى-الأقصى) لهذه الأعرضة عبر مواد كل سلسلة. بدائل الجمعة (عدة
ملفات) تُعامَل بنفس المنطق لكن كمجموع واحد: مجموع مددها هو ما يحدد عدد
الفترات المحجوزة، بصرف النظر عن عددها.

خيار "ملء الفراغات بين السلاسل بفواصل" (أعلى لوحة "ترتيب 8 ساعات"): عند
تفعيله، أي فراغ ظاهر بين السلاسل باللوحة يُملأ عند البناء بفواصل بمعدل
نصف ساعة تقريباً لكل مربع فارغ بدل تجاوزه، لبناء قائمة تشغيل يومية متواصلة
حتى مع وجود فجوات بين السلاسل في اللوحة.

## التشغيل من الكود المصدري

يتطلب Python 3.10 أو أحدث.

```bash
pip install -r requirements.txt
python main.py
```

## تحويله إلى برنامج تنفيذي (.exe) لويندوز

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name "منظم_قوائم_التشغيل" main.py
```

سيظهر الملف التنفيذي داخل مجلد `dist`. يمكن إضافة أيقونة عبر `--icon=path\to\icon.ico`.

## تصدير/استيراد نتائج الفحص

فحص مكتبة ضخمة (قراءة مدد آلاف الملفات الصوتية) قد يستغرق وقتاً طويلاً. في
تبويبي "سلاسل المواد" و"الفواصل"، بعد أي فحص ناجح يمكن الضغط على "💾 تصدير
نتائج الفحص" لحفظ كل النتائج (بما فيها المدد المقروءة) في ملف JSON واحد.
لاحقاً (مثلاً بعد إعادة تشغيل البرنامج للاختبار)، الضغط على "📂 استيراد نتائج
فحص محفوظة" يستعيد نفس النتائج فوراً دون لمس القرص إطلاقاً أو إعادة قراءة أي
ملف صوتي.

## تصدير/استيراد المشروع الكامل

في تبويب "الإعدادات"، زر "💾 تصدير المشروع الكامل" يحفظ **كل شيء** في ملف
JSON واحد: نتائج فحص السلاسل والفواصل، ترتيب لوحة "ترتيب 8 ساعات" الكامل
(موضع كل سلسلة بالضبط)، بدائل "ترتيب 24 ساعة" (الفجر/المساء/الجمعة)، جدول
نسب الفواصل بترتيبه وبادئاته، قائمة الاستثناءات، وكل قيم تبويب الإعدادات
والمسارات. زر "📂 استيراد المشروع الكامل" يستعيد كل هذا دفعة واحدة، فتصبح
جاهزاً للمتابعة أو التخريج مباشرة دون إعادة أي خطوة يدوية.

## الجدول الشامل عند التخريج

بدل ملف `manifest.csv` منفصل داخل كل مجلد يوم، يُنشئ التخريج الآن **ملفاً
واحداً** باسم `جدول_التخريج.xlsx` مباشرة في جذر مجلد الإخراج، بصفحة (sheet)
منفصلة لكل يوم، تسهّل المراجعة والمشاركة بدل تصفح عشرات المجلدات.

## استثناء ملفات من الفحص

تبويب "استثناءات" يحوي قائمة **بأسماء ملفات** (وليس مسارات كاملة) — أي ملف
في أي مكان بالمكتبة يحمل أحد هذه الأسماء بالضبط (بلا حساسية لحالة الأحرف)
يُستبعد تلقائياً من أي فحص لاحق (سلسلة، بادئة، أو فاصل)، بغضّ النظر عن مساره.
مثال عملي: إن كان لمادة واحدة عدة نسخ بجودات مختلفة ويُختار أكبرها تلقائياً،
واستثنيتَ اسم تلك النسخة الأكبر، يُختار تلقائياً ثاني أكبر نسخة متبقية بدلاً
منها. يمكن الإضافة بثلاث طرق: زر "إضافة ملف/ملفات" (اختيار عدة ملفات دفعة
واحدة)، أو زر "إضافة كل ملفات مجلد" (يستخرج أسماء كل الملفات داخل مجلد
وفروعه ويضيفها جميعاً)، أو ببساطة عبر تحرير القائمة يدوياً. القائمة تُحفظ
تلقائياً بين مرات التشغيل، لكن تطبيقها يحدث فقط عند إجراء فحص جديد — أعد
الفحص (أو استورد نتيجة فحص قديمة ثم أعد الفحص) لتفعيل استثناء أُضيف حديثاً.

## بنية الملفات

| الملف | الدور |
|---|---|
| `main.py` | الواجهة الرسومية الكاملة (8 تبويبات، 4 أوضاع مظهر قابلة للتبديل، تبويب "حول") |
| `library_scanner.py` | فحص بنية السلاسل/الفواصل/البادئات (بالتوازي)، وتخمين نوع السلسلة من رمزها |
| `exclusions.py` | قائمة أسماء الملفات المستثناة عالمياً (تُستشار من audio_utils.is_audio_file) |
| `grid_widget.py` | لوحة "ترتيب 8 ساعات" التفاعلية (عرض متدرّج لكل مادة، بحث سريع بمصفوفة ارتفاعات) + لوحة "ترتيب 24 ساعة" للقراءة فقط |
| `playlist_builder.py` | محرك البناء اليومي (DailyScheduleBuilder + FasilPool): مؤشر زمني، ملء دقيق للفقرات، نسخ آمن، جدول Excel شامل |
| `models.py` | FasilConfig ولقطات اللوحتين الثابتة (GridSnapshot/OverrideSnapshot) المُمرَّرة لخيط البناء |
| `audio_utils.py` | قراءة مدد الملفات الصوتية بالتوازي (mutagen) مع ذاكرة مؤقتة للمدد، ويستشير `exclusions.py` |
| `theme.py` | نظام الأوضاع الأربعة (ليليان + نهاريان) القابل للتوليد بلون مميّز لكل وضع |

## ملاحظات الأداء (لمكتبات ضخمة: مئات السلاسل/آلاف المواد)

- **فحص المكتبة**: قراءة مدد الملفات تتم بالتوازي عبر مجمّع خيوط (16 خيطاً
  افتراضياً) بدل ملفاً تلو الآخر، ما يسرّع الفحص عدة أضعاف خصوصاً مع ملفات
  كثيرة أو مسارات شبكية/تخزين أبطأ.
- **الإضافة للوحة "ترتيب 8 ساعات"**: تبحث عن مكان فارغ باستخدام مصفوفة
  ارتفاعات لكل عمود (بدل فحص كل خلية بكل سطر)، فتنتقل من عملية قد تستغرق
  دقائق مع مئات السلاسل إلى أقل من ثانية.
- إن كانت مدة نطاق التاريخ أقل من عدد مواد سلسلة ما، سيتعذّر وضعها؛ هذا حدّ
  سعة طبيعي (وليس خللاً) — وسّع المدى الزمني لاستيعاب أكبر سلسلة لديك.

## تحديث المشروع من الموبايل (استبدال تلقائي)

ارفع ملف `.zip` للمشروع إلى **جذر** المستودع (Add file → Upload files). يعمل الـ workflow
`.github/workflows/extract-zip.yml` تلقائياً: يستخرج الأرشيف، يحذف الملفات القديمة، ينسخ الجديدة
(حتى لو كانت داخل مجلد واحد)، يحذف ملف الـ zip، ثم يعمل commit ووسماً من قيمة `APP_VERSION`.
